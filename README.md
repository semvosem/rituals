# Ритуалы для команды

Одностраничное приложение для автоматического определения ведущих командных ритуалов на текущую и следующую неделю.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Участники

Список участников редактируется в [`src/config/participants.ts`](src/config/participants.ts).

Очередь ведущих **общая** для всех ритуалов. Один участник не может вести больше одного ритуала за неделю. Женя ведёт планирование по умолчанию; в отпуске его замещает следующий из очереди.

## Архив

Отдельная страница: `/#/archive` — ритуалы, отпуска за неделю и изменения очереди.

## Деплой на GitHub Pages

1. В репозитории на GitHub: **Settings → Pages → Build and deployment → Source** → `GitHub Actions`.
2. Убедитесь, что репозиторий называется `Rituals` (или обновите `base` в [`vite.config.ts`](vite.config.ts)).
3. Запушьте код в ветку `main` — workflow опубликует приложение автоматически.

Сайт будет доступен по адресу: `https://<username>.github.io/Rituals/`
